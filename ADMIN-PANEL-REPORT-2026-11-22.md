# Отчёт: панель администратора SaudaPulse — 22.11.2026

Админка работает с миграциями 018 и 020. Для 019 (реферальная программа) в неё добавлена метка реферала. На живой базе `zraktrilvwrfpcbmkqwi` метки пока не появятся: миграции 019, 020 и новая 021 туда ещё не применены.

Пошаговое руководство по открытию и правам: `ADMIN-PANEL-GUIDE-2026-11-22.md`.

## 1. Где панель и как её открыть

- Файлы: `kaspi-seller-hub/billing/admin/index.html`, `admin.js`, `admin.css`.
- Открывается двойным щелчком по `index.html`, сервер не нужен.
- Один раз вводятся адрес проекта (`https://zraktrilvwrfpcbmkqwi.supabase.co`) и публичный ключ. Вход по коду на почту.
- Изоляция проверена: панели нет ни в публичном сайте, ни в расширении.
  - в `dist/site/` упоминаний `admin` нет;
  - в `dist/kaspi-seller-hub-0.1.0.zip` упоминаний `admin` нет;
  - `tools/build-site.mjs` берёт только `site/`, а `tools/build-release.mjs` папку админки не включает.

## 2. Как стать администратором

1. Один раз войдите под своей почтой в расширение, чтобы аккаунт появился в `auth.users`.
2. В SQL Editor проекта `zraktrilvwrfpcbmkqwi` выполните (подставьте свою почту):

```sql
insert into public.admins (user_id) select id from auth.users where email = 'ВАШ_EMAIL' on conflict do nothing;
```

3. Проверка — запрос должен вернуть вашу почту:

```sql
select u.email from public.admins a join auth.users u on u.id = a.user_id;
```

4. Снять права:

```sql
delete from public.admins where user_id = (select id from auth.users where email = 'ВАШ_EMAIL');
```

`is_admin()` проверяет, есть ли текущий пользователь в таблице `public.admins` (`001_billing.sql:190-193`). У таблицы включён RLS без политик, поэтому клиенты её не видят.

## 4. Что добавлено

- **Миграция `kaspi-seller-hub/billing/supabase/021_admin_referral_info.sql`**, применять после 019 и 020.
  - `admin_invoices` теперь отдаёт `referred`, `referrer_email`, `referral_rewarded`, `referral_will_reward`.
  - `admin_accounts` теперь отдаёт `referred`, `referrer_email`, `referrals_count`, `referral_bonus_days`, `referral_code`.
- **Метки в `admin.js` и `admin.css`.** Строятся только через текстовые узлы, без `innerHTML`.
  - На ожидающем счёте видно, по чьей ссылке пришёл клиент, и что будет при нажатии «Оплата получена»: пригласившему +14 дней, бонус уже начислен или бонус не положен (например, за оплату дополнительных магазинов).
  - В карточке клиента — его код, сколько людей он пригласил, сколько бонусных дней получил и чья ссылка его привела.
- **Тесты:** `tests/sql/test18.sql` — 6 проверок: поля о рефералах видны админу, замороженный пригласивший бонус не получает, не-админу функции недоступны. `tests/sql/run.sh` загружает 021.

## 5. Возможности админки по вкладкам

| Вкладка | Что можно делать |
|---|---|
| Пульт | Сводные показатели, воронка, удержание, NPS (`admin_insights`) |
| Ждут оплаты | Подтвердить счёт Kaspi Pay кнопкой «Оплата получена» (`admin_confirm_invoice`) или отменить его (`admin_cancel_invoice`); метка реферала |
| Оплаченные / Все счета | История счетов (`admin_invoices`) |
| Клиенты | Список клиентов, добавить дни подписки или триала (`admin_grant_days`), данные о рефералах |
| Вопросы | Обращения в поддержку и ответы на них (`admin_tickets`, `admin_ticket_reply`) |
| Состояние | Статус сервиса, здоровье API, ключи `OPS_KEY` и `BOT_KEY`, системная плашка (`admin_set_status`, `admin_health`, `admin_ops_settings`, `admin_set_system_banner`) |
| Фича-флаги | Создать, изменить или удалить флаг (`admin_*_feature_flag`) |
| Цены и QR | Тарифы, QR для оплаты, срок заморозки `freeze_days`, настройки роста (`admin_get_config`, `admin_update_config`, `admin_growth_settings`) |

Чего в админке нет:
- Кнопки заморозки или блокировки. Заморозку включает сам клиент в расширении, а в админке задаётся только её длительность (`freeze_days`). Признак `trial_blocked` показывается меткой.
- Кнопок для `admin_delete_account` и `admin_purge_expired`. Эти функции есть в миграции 014, но в интерфейсе не используются.
- Команд администратора в Telegram-боте. Бот только шлёт уведомления продавцам (`/start <token>`, `/stop`).
