# Основания для блока подключения

Проверено 19 ноября 2026 года. Kaspi указывает, что токен получает руководитель компании в веб-версии кабинета продавца: «Настройки → Токен API → Сформировать». Затем токен копируется. Держатель токена может получать информацию о заказах и товарах. Kaspi предупреждает не раскрывать токен посторонним, кроме технического специалиста своей компании.

Источники: https://guide.kaspi.kz/partner/ru/shop/api/general/q3196 и https://guide.kaspi.kz/partner/ru/shop/api/general/q3193.

На лендинге показана схема, а не точная копия интерфейса Kaspi. Используется вымышленный токен с префиксом DEMO-. Кнопки меняют только демонстрационное состояние; отсутствуют ввод реальных токенов, Clipboard API, хранилище токенов и запросы Kaspi API.

Нельзя переносить свойства этого демо на реальный SaaS: интеграция передаёт токен сервису и получает данные магазина по API. Локальное хранение, отсутствие передачи третьим лицам, размещение в Казахстане, шифрование и сроки хранения не подтверждены текущим кодом лендинга. Такие гарантии требуют проверки backend, инфраструктуры и политики обработки данных.

## Область доступа к магазину и банковский счёт

Проверено 20 ноября 2026 года. Официальное описание токена (https://guide.kaspi.kz/partner/ru/shop/api/general/q3195) относит его к кабинету продавца Магазина и доступу к заказам и товарам. Инструкция API (https://guide.kaspi.kz/partner/ru/shop/api/general/q3193) описывает добавление товаров и обработку заказов. В данных заказа присутствует totalPrice — сумма заказа, а также данные покупателей, способы оплаты и доставки (https://guide.kaspi.kz/partner/ru/shop/api/orders/q3201).

Для блока лендинга допустимо объяснить границу предлагаемой схемы: используется API-токен Магазина, а банковский кабинет не подключается; пароль банковского кабинета, PIN, SMS-коды и реквизиты счёта для этой формы подключения не нужны. Суммы заказов в аналитике — не банковский баланс.

В этих источниках нет самостоятельной гарантии «сервис никогда не узнает никаких банковских реквизитов», а реальный backend SaaS ещё не проверен. Не обещать такое, а также отсутствие любой передачи данных, банковскую сертификацию, готовую локализацию или доказанное шифрование. Указанная граница описывает подключение по API Магазина, а не результат аудита всего продукта. Токен остаётся чувствительным: holder может получать данные магазина и выполнять поддерживаемые операции; не называть доступ read-only.
