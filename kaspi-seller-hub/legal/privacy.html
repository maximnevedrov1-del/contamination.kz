1. Назначение расширения

Расширение SaudaPulse решает одну задачу: помогает продавцу Kaspi.kz управлять своим магазином — заказами, каталогом, ценами, остатками, себестоимостью, сообщениями и накладными — в одном кабинете. Данные используются только для этой задачи.

3. Что остаётся только в вашем браузере

Следующие данные хранятся локально в chrome.storage вашего браузера и не отправляются на наш сервер и третьим лицам:

  • токены Kaspi API — зашифрованы алгоритмом AES-GCM 256 с неизвлекаемым ключом и никуда не передаются, кроме запросов к Kaspi.kz, которые вы инициируете;
  • заказы, каталог товаров, себестоимость, сообщения покупателей, накладные.

Удаление расширения или очистка данных браузера удаляет эти данные.

4. Автоматическая загрузка прайс-листа

Если вы сами включите автоматическую загрузку прайс-листа, Сервис формирует XML-файл с ценами и остатками вашего магазина и размещает его по секретной публичной ссылке, чтобы Kaspi.kz мог его считывать. Без включения этой функции файл не создаётся. Не передавайте ссылку посторонним; отключение функции прекращает обновление файла.

5. Правовые основания и цели

Данные обрабатываются на основании вашего согласия, которое вы даёте при входе в Сервис, и для исполнения договора (публичная оферта). Цели: создание и защита Аккаунта, предоставление функций Сервиса, приём оплаты, поддержка пользователей, исполнение требований законодательства.

Использование и передача информации, полученной через API Google, а также данных пользователей расширения будут соответствовать Политике в отношении пользовательских данных Chrome Web Store, включая требования об ограниченном использовании. Данные используются только для работы единственной заявленной функции расширения (раздел 1), не передаются и не продаются для рекламы, не используются для оценки кредитоспособности и не читаются людьми, кроме случаев: вы дали согласие (например, отправили обращение в поддержку), это нужно для безопасности или этого требует закон.

9. Защита данных

  • передача данных только по HTTPS;
  • защита на уровне строк базы данных (row-level security): каждый клиент видит только свои данные;
  • локальное шифрование токенов Kaspi API (AES-GCM 256, неизвлекаемый ключ);
  • минимизация: мы не собираем то, что не нужно для работы функций.

В случае утечки персональных данных мы уведомим затронутых пользователей и уполномоченные органы в порядке и сроки, установленные законодательством Республики Казахстан.

10. Ваши права

Вы вправе: узнать, какие данные о вас обрабатываются; получить их копию; требовать исправления, блокирования или удаления данных; отозвать согласие; обратиться в уполномоченный орган. Запрос направляется на support@saudapulse.kz с адреса почты Аккаунта. Удаление данных выполняется в течение 30 дней; записи об оплатах и согласиях сохраняются в сроки, предусмотренные законом. Отзыв согласия может сделать невозможным использование Сервиса.
