2. Термины

  • Сервис — расширение для браузера Google Chrome «Kaspi Seller Hub» и серверная часть для аккаунтов и подписок. Сервис собирает в одной панели заказы, возвраты, отказы, оплаты, аналитику и чат нескольких магазинов Клиента на Kaspi.kz.
  • Аккаунт — учётная запись Клиента, созданная при первом входе по адресу электронной почты и одноразовому коду.
  • Магазин — магазин Клиента на Kaspi.kz, подключённый к Сервису через токен API или открытую вкладку кабинета продавца.
  • Токен API — ключ доступа к API Магазина на Kaspi.kz, сформированный Клиентом в кабинете продавца.
  • Подписка — право пользоваться Сервисом для определённого числа Магазинов в течение оплаченного Периода.
  • Период — пробный период или оплаченный календарный месяц (несколько месяцев) Подписки.
  • Счёт — сумма к оплате, которую Сервис показывает Клиенту с QR-кодом Kaspi и номером счёта.

7.1. За 5 календарных дней до окончания Периода Сервис выставляет один Счёт на следующий месяц за все подключённые Магазины и уведомляет Клиента в интерфейсе Сервиса и уведомлением браузера.
