## 2. Резервная копия локальных данных

- В «Настройках» есть кнопки «Экспорт данных (JSON)» и «Импорт из файла», на KK — «Деректерді экспорттау (JSON)» и «Файлдан импорттау».
- **Что входит в бэкап:** заказы (snapshots по магазинам), себестоимость, настройки, название и цвет магазинов, каталог, фиды, фото.
- **Что не входит:** токены Kaspi (`ksh.apiTokens`), сессия и лицензия. Они не экспортируются и не перезаписываются.
- **Проверка файла:** импорт принимает только файлы с `app` и `version === 1`. Старые файлы без заказов тоже импортируются.
- **Поведение импорта:** заказы восстанавливаются только у подключённых магазинов, в которых ещё нет заказов. Уже существующие данные сохраняются.
- **Не проверено:** отдельного теста на импорт нет, вживую импорт не запускался.
