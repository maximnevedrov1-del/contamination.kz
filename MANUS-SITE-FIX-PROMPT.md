## 1. Рабочие кнопки установки и открытия расширения (главное)

Сейчас все кнопки «Установить бесплатно», «Начать 14 дней бесплатно» и «Попасть в пилот» ведут на `#pilot`, к форме в деморежиме. Посетитель упирается в тупик. Сделай так:

1. В `<head>` добавь две настройки:
   ```html
   <meta name="sp-extension-id" content="">
   <meta name="sp-store-url" content="">
   ```
   Значения я заполню сам после публикации в Chrome Web Store. Пока они пустые, сайт обязан работать по запасному сценарию из п. 4.

2. Всем кнопкам «Установить бесплатно» и «Начать 14 дней бесплатно» (в шапке, на первом экране, в тарифах, в калькуляторе, в финальном блоке) добавь атрибут `data-sp-install`. Кнопкам «Попасть в пилот» поменяй текст на «Попробовать 14 дней бесплатно» и тоже добавь `data-sp-install`. Ссылка `href="#install"` остаётся запасной.

3. Перед `</body>` вставь этот скрипт без изменений:
   ```html
   <script>
   (function () {
     var meta = function (n) { var m = document.querySelector('meta[name="' + n + '"]'); return m ? (m.content || '').trim() : ''; };
     var EXT_ID = meta('sp-extension-id');
     var STORE_URL = meta('sp-store-url');
     var REF_RE = /^SP-[A-Z0-9]{6}$/;
     // Реферальный код из ссылки ?ref=SP-XXXXXX запоминаем и передаём расширению при открытии.
     try {
       var q = (new URLSearchParams(location.search).get('ref') || '').trim().toUpperCase();
       if (REF_RE.test(q)) localStorage.setItem('sp_ref_code', q);
     } catch (e) {}
     var ref = function () { try { var v = localStorage.getItem('sp_ref_code'); return v && REF_RE.test(v) ? v : undefined; } catch (e) { return undefined; } };
     var isDesktopChrome = function () {
       return !!window.chrome && /Chrome\//.test(navigator.userAgent) && !/Android|iPhone|iPad|Edg\/|OPR\//.test(navigator.userAgent);
     };
     var goInstall = function () {
       if (STORE_URL) { window.open(STORE_URL, '_blank', 'noopener'); return; }
       var s = document.getElementById('install'); if (s) s.scrollIntoView({ behavior: 'smooth' });
     };
     // 1) Расширение уже стоит → открываем его панель. 2) Не стоит → магазин Chrome. 3) Магазина ещё нет → блок #install.
     document.querySelectorAll('[data-sp-install]').forEach(function (a) {
       a.addEventListener('click', function (ev) {
         ev.preventDefault();
         if (!isDesktopChrome()) { var s = document.getElementById('install'); if (s) s.scrollIntoView({ behavior: 'smooth' }); return; }
         if (!EXT_ID || !(window.chrome && chrome.runtime && chrome.runtime.sendMessage)) { goInstall(); return; }
         var done = false;
         var timer = setTimeout(function () { if (!done) { done = true; goInstall(); } }, 800);
         try {
           chrome.runtime.sendMessage(EXT_ID, { type: 'OPEN_DASHBOARD', ref: ref() }, function (res) {
             void chrome.runtime.lastError;
             clearTimeout(timer);
             if (done) return; done = true;
             if (!(res && res.ok)) goInstall();
           });
         } catch (e) { clearTimeout(timer); if (!done) { done = true; goInstall(); } }
       });
     });
     // Показываем «Открыть SaudaPulse», если расширение уже установлено.
     if (EXT_ID && isDesktopChrome() && chrome.runtime && chrome.runtime.sendMessage) {
       try {
         chrome.runtime.sendMessage(EXT_ID, { type: 'PING' }, function (res) {
           void chrome.runtime.lastError;
           if (res && res.ok) document.querySelectorAll('[data-sp-install]').forEach(function (a) {
             if (a.dataset.openLabel) a.textContent = a.dataset.openLabel;
           });
         });
       } catch (e) {}
     }
   })();
   </script>
   ```
   Каждой кнопке с `data-sp-install` добавь `data-open-label="Открыть SaudaPulse"` (в казахской версии — «SaudaPulse ашу»). Кнопки остаются ссылками `<a>`, чтобы работать и без JavaScript.

4. Добавь новую секцию `<section id="install">` перед тарифами, в стиле сайта. Заголовок «Как установить». Три шага:
   1) «Откройте сайт в Google Chrome на компьютере»;
   2) «Нажмите „Установить“ — откроется магазин Chrome»;
   3) «Закрепите значок SaudaPulse и подключите магазин по API-токену».

   Под шагами — кнопка «Установить в Chrome» с `data-sp-install` и вторая кнопка «Написать в Telegram» (`https://t.me/SaudaPulse`, `target="_blank" rel="noopener"`). Если открыто с телефона (Android/iPhone/iPad), покажи над шагами плашку: «SaudaPulse работает в Chrome на компьютере. Отправьте себе ссылку и откройте её на ПК» и кнопку «Скопировать ссылку» (копирует `https://saudapulse.kz`). Если `sp-store-url` пустой, под кнопкой мелким текстом: «Публикация в магазине Chrome — скоро. Напишите нам в Telegram, пришлём установочный файл».

## 2. Форма заявки: убрать тупик

Форма внизу сейчас «работает в деморежиме и не отправляет данные». Сервера для заявок нет, поэтому сделай так:
- Убери фразу про деморежим.
- Кнопку формы переименуй в «Отправить в Telegram». По нажатию проверь согласие и имя с контактом. Собери текст: «Заявка SaudaPulse: {имя}, {контакт}, магазинов: {выбор}, заказов в день: {выбор}». Скопируй его в буфер (`navigator.clipboard.writeText`, при ошибке — через выделение текста) и открой `https://t.me/SaudaPulse` в новой вкладке. Покажи сообщение: «Текст заявки скопирован — вставьте его в чат и отправьте».
- Рядом дай ссылку «или на почту»: `mailto:support@saudapulse.kz?subject=Заявка SaudaPulse&body=<тот же текст, закодированный encodeURIComponent>`.

## 4. Тарифы

- Цены не трогай: 12 000 / 20 000 / 25 000 / 30 000 ₸, слот +5 000 ₸ — они совпадают с программой.
- В программе все функции доступны на любом тарифе, ограничено только число магазинов. Поэтому в карточках оставь пункты одинаковой сути и не создавай впечатления, что функции заперты в старших тарифах. «Один магазин»: «Заказы и статусы • Накладные • Кабинет сборщика • Аналитика». Старшие карточки: «Всё из „Один магазин“ • N Kaspi-магазинов в одной очереди».
- В карточке «Дополнительный слот» убери кнопку «Начать 14 дней бесплатно». Вместо неё — текст «Докупается в расширении в разделе „Подписка“».

## 5. Проверка перед сдачей

- Ни одна кнопка не ведёт на несуществующий якорь: проверь, что `#install`, `#live-demo` и якоря меню существуют.
- При ширине 390 px нет горизонтальной прокрутки; новая секция и плашка для телефона выглядят аккуратно.
- В консоли браузера нет ошибок, если `sp-extension-id` и `sp-store-url` пустые.
- Казахская версия содержит все новые тексты, без русских остатков в новых блоках.
- Не добавляй внешних скриптов, трекеров и шрифтов сверх уже подключённых.
- Футер (ИП, ИИН, Оферта, Политика, Telegram, почта) оставь как есть.

## После публикации в Chrome Web Store (для владельца)

1. В файле сайта заполните:
   - `<meta name="sp-store-url" content="https://chromewebstore.google.com/detail/…">` — ссылка на страницу расширения;
   - `<meta name="sp-extension-id" content="…32 буквы…">` — ID из той же ссылки (последняя часть адреса).
2. Кнопка «Открыть SaudaPulse» сработает только на `https://saudapulse.kz` и его поддоменах: только им расширение разрешает с собой говорить (`externally_connectable` в `manifest.json`). При открытии файла с компьютера или с другого домена кнопки просто ведут в магазин. Это нормально.
